## Project Overview

This repository contains the Software Requirements Engineering (SWRE) project developed by Team 7, SpecOps.
Our project focuses on the **UTM QV SAMC Management System**, which aims to improve the current management of the SAMC verification system in UTM.
The proposed system is designed to support the application, evaluation, approval and ongoing monitoring of SAMC applications through a centralized platform.
